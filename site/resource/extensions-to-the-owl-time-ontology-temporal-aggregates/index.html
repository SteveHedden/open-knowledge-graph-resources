Extensions to the OWL-Time Ontology - temporal aggregates

Also known as: vocab-owl-time-agg

Ontology Technology & Web

This note adds one new class time:TemporalAggregate and two properties time:hasPart and its inverse time:isPartOf to allow for the description of arbitrary aggregates of temporal entities.
